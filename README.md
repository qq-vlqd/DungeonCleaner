# Dungeon Cleaner: Slime's Revenge

Проект разработан в рамках игрового хакатона **FEIS Game Jam 2026** под тему *«Roles Reversed» (Роли поменялись местами)*.

## 📝 Описание концепта
Все мы знаем истории про отважных рыцарей, которые пачками зачищают подземелья. Но никто никогда не спрашивал: а кто убирает весь этот бардак? Роли поменялись! Вы играете за маленького зеленого Слайма-Дворника, который вынужден бегать по пятам за тупым, перекачанным автоматическим Рыцарем. Этот железный лоб несётся вперед, ломает сундуки и шинкует монстров в пиксельный фарш, оставляя после себя горы мусора и лужи крови. Если подземелье станет слишком грязным — ВЫ ПРОИГРАЛИ! Собирайте монеты, покупайте улучшения и продержитесь достаточно долго, чтобы устроить брутальную месть этому злому рыцарю!

- **Платформа:** WebGL (Браузерная версия)
